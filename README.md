# Drivezy Car Booking

## Run locally

Install dependencies once:

```sh
npm install
```

Start the web app and JSON Server together:

```sh
npm run dev:all
```

Open the Vite URL shown in the terminal. JSON Server runs at `http://localhost:3500`; cars and bookings are served from `db.json`.

To run either process separately, use `npm run dev` for Vite or `npm run server` for JSON Server.
